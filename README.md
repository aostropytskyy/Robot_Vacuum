# Robot Vacuum Project
## Description
### A robot Vacuum with future plans to integrate ros2 and designed to be autonomous


## Parts list
### 2x Motors with encoders
### Ultrasonic sensor
### ESP32 wroom E 
### 3x Motor drivers (DRV8833)
### DC-DC converter step down
### 8.4v 2400mAh NimH Battery
### Jumper wires
### Gyroscope and accelleromotor (MPU) 
### Resistors for voltage divider to provide ESP32 3.3v
